# Galen Oakes

I spent twenty years as a photographer and creative director. In April 2025 I wrote my first line of code. I build [Braintied](https://braintied.com).

People talk. Agents ship. Every venture that comes out the other side inherits the back office.

## Braintied

The company and the stack. The apps are surfaces on it.

- [Sentigen](https://www.braintied.com/brands/sentigen): system of record. Meetings, mail, people, the work.
- [Ora](https://www.braintied.com/brands/ora): the agent OS.
- [Kulti](https://kulti.live): the stage. Work ships in public.
- [Parlor](https://www.braintied.com/brands/parlor): a production site from a conversation.
- [Swishh](https://www.braintied.com/brands/swishh): content, social, affiliates. One engine.

The long version is the [founder page](https://www.braintied.com/founder).
